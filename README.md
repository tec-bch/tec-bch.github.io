# TEC website — GitHub Pages wrapper

หน้านี้แสดงเว็บ TEC (Google Apps Script) แบบเต็มจอ ภายใต้ลิงก์ github.io

- `index.html` – หน้าหลัก (แก้ลิงก์เว็บได้ที่บรรทัด `var APP_URL = ...`)
- `logo.png` – ไอคอนบนแท็บเบราว์เซอร์ (เปลี่ยนเป็นโลโก้ TEC จริงได้ ใช้ชื่อไฟล์เดิม)
- `share.jpg` – ภาพตัวอย่างเวลาแชร์ลิงก์ทาง LINE / Facebook (1200×630)

ลิงก์ไปหน้าเฉพาะ: `https://<ชื่อบัญชี>.github.io/?page=care&id=abdomen`
